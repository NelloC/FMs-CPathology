# Benchmarking Vision Foundation Models in Computational Pathology on Public Datasets

Code, split manifests and environment for the paper. License: MIT (`LICENSE`).

## Environment
- Python 3.12.3, CUDA 13.0, cuDNN 9.19; NVIDIA DGX Spark (GB10 GPU, ARM CPU).
- Exact package versions: `requirements.lock`.

## Model checkpoints
Hugging Face repositories and revision hashes: `REVISIONS` in `pipeline/models.py` (also Table I).
CTransPath: TransPath release weights (`ctranspath.pth`, not redistributed), placed in `weights/` (or `$VFM_WEIGHTS_DIR`); SHA-256 `7c998680060c8743551a412583fac689db43cec07053b72dfec6dcd810113539`.

## Datasets and preprocessing
- Datasets are used as distributed by their authors (sources cited in the paper), placed under `$VFM_BASE_DIR/dataset/`. The exact files used are listed in `manifests/`. The per-dataset file indexes (`indexes/`) are generated by the first commands below; the LC25000 source-image groups used in the paper are included (`indexes/lc25000_source_groups.csv`).
- Copies used for BreaKHis and LC25000: Kaggle `waseemalastal/breakhis-breast-cancer-histopathological-dataset` (v1; 224×224 images) and `javaidahmadwani/lc25000` (v1; "Train and Validation Set" folder).
- Tiling (PANDA, BACH, HuBMAP): non-overlapping 256×256 tiles. PANDA: OpenSlide, pyramid level 1 (4× downsampled from full resolution), JPEG; tiles with >60% of pixels above grayscale 230 discarded; each tile takes its slide's ISUP grade. BACH and HuBMAP: Pillow, uncompressed TIFF; tiles with >90% such pixels discarded; labels from `microscopy_ground_truth.csv` (BACH) and the organ in the official metadata (HuBMAP).
- Tissue filter applied to these tiles (≥10% tissue): `pipeline/tissue.py`. LC25000 source-image groups: `pipeline/lc25000_groups.py`. BRACS fixed-resolution tiles: `pipeline/tile_bracs.py`.

## Split manifests
`manifests/<dataset>/seed<k>.csv.gz` (seeds 42–46; `seedofficial` for BRACS and SICAPv2): partition of every image; checksums in `manifests/SHA256SUMS`.

## Commands
Run from this folder with `export VFM_BASE_DIR=<folder containing dataset/>`, `M="phikon ctranspath vit_in1k conch uni2h virchow2"` and `V="phikon vit_in1k conch uni2h virchow2"` (CTransPath has no class or patch tokens).

```
python pipeline/lc25000_groups.py
python pipeline/data_index.py && python pipeline/data_index.py nct_val7k
python pipeline/tissue.py panda bach hubmap
python pipeline/export_manifests.py
python pipeline/verify_models.py
python pipeline/extract.py --models $M --datasets breakhis lung bach hubmap sicap nct panda bracs nct_val7k
python pipeline/probe.py --models $M --datasets breakhis lung bach hubmap sicap nct panda bracs
python pipeline/probe.py --models $V --datasets breakhis lung bach hubmap sicap nct panda bracs --key cls
python pipeline/probe.py --models $V --datasets breakhis lung bach hubmap sicap nct panda bracs --key patch_mean
python pipeline/probe.py --models $M --datasets lung breakhis bach hubmap panda --split image
python pipeline/abmil_panda.py --models $M
python pipeline/external.py --models $M
python pipeline/tile_bracs.py && for m in $M; do python pipeline/extract_tiles.py --models $m; done
python pipeline/probe.py --models $M --datasets bracs --features features_bracs_tiles --out results/probe_bracs_tiles
python pipeline/stats.py --models $M
python pipeline/stats.py --models $M --probe-dir results/abmil --out results/stats_abmil --datasets panda
python pipeline/stats.py --models $M --probe-dir results/external --out results/stats_external --datasets nct_val7k
python pipeline/precision.py --models $M
python pipeline/extract.py --models hoptimus0 gigapath --datasets breakhis lung bach hubmap sicap nct panda bracs
python pipeline/probe.py --models hoptimus0 gigapath --datasets breakhis lung bach hubmap sicap nct panda bracs
python pipeline/report.py --models $M --out generated
```
